# Referee Select

## Description

Allows you to use any wrestler in the game as a referee. Once installed, you can select your preferred referee directly from the in-game Options menu.

## Requirements

- [UE4SS v4.0.0](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v4.0.0) or later.

## Installation

1. Download and install [UE4SS v4.0.0](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v4.0.0) or later.
2. Extract the `RefereeSelect` folder into your game's `ue4ss/Mods` directory.
3. Ensure that an `enabled.txt` file is present inside the mod folder.

## Selecting a Referee

1. Launch the game with the mod installed.
2. Open the in-game **Options** menu.
3. Navigate to the **Match** options.
4. Choose the wrestler you want to use as the referee.

Your selected wrestler will be used as the referee in matches.
